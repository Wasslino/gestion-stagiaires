Sauvegarde & installation

Tes données restent sur ce téléphone

Tout est enregistré dans le navigateur de cet appareil — rien n'est envoyé sur Internet et l'application fonctionne hors ligne. Si tu changes de téléphone ou si tu vides le cache du navigateur, les données disparaissent : exporte régulièrement une sauvegarde.

Exporter une sauvegarde

Télécharge un fichier contenant tous tes stagiaires, matières, créneaux et paiements. Garde-le en lieu sûr (par exemple, envoie-le-toi sur WhatsApp ou par e-mail).

Importer une sauvegarde

Restaure un fichier exporté précédemment. Attention : l'import remplace toutes les données actuelles de l'application.

Installer sur l'écran d'accueil

Pour ouvrir l'application comme une vraie application, sans passer par le navigateur :

  1. Android (Chrome) : ouvre cette page dans Chrome, touche le menu ⋮ en haut à droite, puis « Ajouter à l'écran d'accueil » (ou « Installer l'application »).
  2. iPhone (Safari) : ouvre cette page dans Safari, touche le bouton Partager, puis « Sur l'écran d'accueil ».
  3. L'icône LinguaLink apparaît sur ton écran d'accueil : un toucher suffit pour ouvrir l'application, même sans connexion.

Zone dangereuse

Efface définitivement toutes les données enregistrées sur cet appareil. Pense à exporter une sauvegarde avant.
